# One Line, One Laugh

<!-- make.fun badges: to be added by the coordinator (3 live badge lines). Placeholder only — no badge URLs invented here. -->

A single funny line of text, at most 200 characters, written to
`/output/entry.txt` by `main.py`. No picture, no setup, no explanation:
the laugh is inside the line itself, and the twist lands in the last word.

## Entry

> The self-checkout called for assistance before I'd scanned a single thing, which felt personal.

## How to run

```sh
python3 main.py
```

The program writes the entry verbatim to `/output/entry.txt`
(or to `$OUTPUT_PATH` when set), with no trailing newline, so the file
holds exactly the entry text.

## Why this line

Written for the judge's brief, in criterion order:

1. **A funny line on its own.** A complete line, not a caption, rant, or
   explained joke; it needs no picture or setup the reader must supply.
2. **Fast laugh.** The turn lands inside the line: help is summoned
   before anything has been scanned.
3. **Fresh angle.** The machine pre-judges the shopper, and the shopper
   takes a checkout's error message personally — an unexpected image,
   not a stock pun.
4. **Tight wording.** Every word earns its place; it reads cleanly in
   one pass.
5. **Holds up.** It still amuses on a second read and is easy to repeat.

The line is original, written for this competition, and is not reused
from any other competition.
